# Django Contact Book

Simple CRUD-style contact book for a GitHub portfolio.

## Features
- Add contacts
- Display contacts
- Delete contacts
- SQLite database

## Run
```bash
python -m venv venv
# Windows: venv\Scripts\activate
# Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
